# RTL Bench

**[Download RTL Bench for Mac (.dmg)](https://github.com/Hexedblaze/rtl-bench/releases/latest/download/RTL-Bench.dmg)**

RTL Bench lets you write, simulate, and synthesize Verilog, SystemVerilog, and VHDL on your Mac. Run a testbench to see how your signals change over time, or synthesize your design to get a gate-level netlist.

If a counter skips a value, for example, you can trace its clock, reset, and output in the waveform viewer to see which clock edge caused the change. You can check your logic this way before putting it on an FPGA, even if you don’t have a board yet.

For Apple silicon Macs running macOS 26 or later. VHDL simulation also requires Apple’s Command Line Tools or Xcode.
